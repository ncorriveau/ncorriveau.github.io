some books and classes I found helpful in my self-taught journey. You should check out [MIT OCW](https://ocw.mit.edu/) and [Stanford Free Courses](https://online.stanford.edu/free-courses) for a ton of high quality free resources.

## 📈 Classic ML / Math

- *Introduction to Linear Algebra* - Strang
  - only linear algebra text book as far as I'm concerned :) super helpful reference to get the basics down.
- *Probability in EE & CS* - Walrand
  - shorter textbook and application driven, so very helpful to get up to speed on some key topics that ties back to how they are actually used.
- *The Elements of Statistical Learning* - Hastie, Tibshirani, Friedman
  - great book to deeply understand classic techniques like linear regression / boosted trees etc. A lot less popular these days...but if you are doing something in predictive modeling still very important.
- *Probabilistic Machine Learning* - Kevin Murphy
  - a 'pre-chatgpt' survey of the world of machine learning / deep learning from a probabilistic lense. I found the notation a bit excessive / hard to follow at times, but still a lot of interesting material here that pairs well with the other books in this list.
- *Convex Optimization* - Boyd
  - the canonical optimization book and class, both freely available online. Useful for deep learning of course, but mathematical optimization is one of the most under appreciated applied fields imo. I am a bit bias though as an OR student :)

## 🤖 Deep Learning & AI

- *Deep Learning* - Ian Goodfellow, Yoshua Bengio, Aaron Courville
  - less relevant now, but the opening chapters are still very helpful for getting the basics of NN down and understanding the history of DL. Will help frame modern transformers / LLMs.
- *Anything Andrej Karpathy related*
  - he is the modern feynman for DL as far as I'm concerned. I'd subscribe to his YT channel, and if you are new to DL, start with this [youtube series](https://www.youtube.com/watch?v=VMj-3S1tku0&list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ)
- *Information Theory, Inference and Learning Algorithms* - David Mackay
  - Highly, highly recommend this book for an engaging and interdisciplinary text that covers how info theory, bayesian inference, and deep learning intertwine. David Mackay's lectures from his Cambridge course that cover a good amount of the book are available on [youtube](https://www.youtube.com/watch?v=BCiZc0n6COY&list=PLruBu5BI5n4aFpG32iMbdWoRVAA-Vcso6) as well.
- *Deep Learning with Python* - Francois Chollet
  - ok yes it teaches 'outdated' frameworks like tensorflow + keras, but if you are starting out I found this book incredibly helpful as a good blend of practical implementations while learning underlying theory as well. Would pair with Goodfelow, Bengio & Courville.
- *Deep Learning Class NYU* - Yann LeCun & Alfredo Canziani
  - I think the most recent recording is from 2021 so a little outdated, and definitely a more theoretical / mathematical approach but great overview of modern research directions (mostly not LLM related). Might be helpful if you are more interested in research than application.
- many many more ... the above will cover all your bases from a theoretical and practical standpoint.

## 💻 Computer Systems

- *[Nand to Tetris](https://www.nand2tetris.org/)*
  - I wish I had done this earlier, it is a gentle and application driven intro into how computers work from first principles basically. You can prob finish it in a couple months while working full time.
- *[Computation Structures MIT](https://ocw.mit.edu/courses/6-004-computation-structures-spring-2017/)*
  - I would define this is as like a more official / classical treatment of Nand to Tetris. I didn't do the whole course but helpful short YT clips for certain topics.
- *Computer Systems - A Programmer's Perspective* - Bryant, O'Hallaron
  - if I had to recommend one book as a must read, it would be this. This was the first time things really clicked for me coming from a non CS background. They have accompanying lectures online. It's long, but can be used as an ongoing reference! Great way to learn C too.
- *Operating Systems - Three Easy Pieces* - Dusseau
  - once you read CSAPP I would follow up with this book / website. Super helpful view into OS and bite size chapters make it easy to consume one piece of material in a day.
- *Computer Networking - A Top Down Approach* - Kurose, Ross
  - a classic text on networking. They have accompanying YT lectures that I watched casually. It was helpful to get up to speed on networking basics. Don't think you need to read full book / class unless you are particularly interested.
- *Designing Data Intensive Application* - Kleppman
  - I feel like people are unjustly hating on this book now, but it is a classic reference on dist systems and the best way to get up to speed quickly on a bunch of topics. It is 'older' but the core principles in it are still the underpinning of modern dist systems.

## ⚛️ Algorithms

- *[Intro to Algorithms](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020)* - MIT
- *[Algorithms 1 & 2](https://www.youtube.com/playlist?list=PLXFMmlk03Dt7Q0xr1PIAriY5623cKiH7V)* - Stanford
- *[Advanced Algorithms](https://web.stanford.edu/class/cs168/index.html)* - Stanford
  - taught by Tim Roughgarden as well, no lectures but excellent materials covering more modern applications, really enjoyed the class notes.
